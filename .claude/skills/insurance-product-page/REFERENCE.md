# Reference — 保险产品页生成规范

## blog-writing-style

通用的读者画像、立场、语言规范、术语对照和信息来源规则，统一见 `writing/写作规范.md`；去 AI 味规则见 `writing/AI味规则.md`（作者维护，优先级最高）。这里只保留产品解析专属的内容。

### 内容优先级（产品解析专属）

写作时按这个优先级分配篇幅：

1. **核心保障（住院 + 外购药械）** — 最大篇幅，这是读者最可能用到的
2. **大病保障（重疾0免赔 + 特药 + 先进疗法）** — 次大篇幅，这是产品的差异化优势
3. **康复 / 护工 / 异地转诊** — 中等篇幅，这些是加分项
4. **可选责任（门急诊）** — 小篇幅，说清楚加不加的判断标准即可
5. **免赔额计算** — 用一个数字例子讲清楚，不要列公式
6. **不保什么** — 列举最常见的几项，不要逐条翻译免责条款
7. **续保规则** — 两句话交代

优势和局限都要讲清楚：硬伤（如不保证续保、仅限普通部）写在读者看得到的正文里，并单独写“适合谁 / 不适合谁”。

## blog-article

### Front Matter 模板

```yaml
---
title: "<产品名>深度解析：<核心卖点>"
date: YYYY-MM-DD
draft: false
categories: ["重疾险"]          # 或 医疗险 / 寿险 / 少儿保险
tags: ["<产品名>", "<公司名>", "重疾险", "保障解析"]
description: "<100字以内摘要，含核心数字>"
cover:
  image: ""
  alt: "<产品名>深度解析"
---
```

### 文章结构（建议顺序，可灵活调整）

以下结构适用于"测评/拆解"型文章。核心逻辑：**从读者最可能用到的场景开始，逐步深入到更小众但重要的保障。**

1. **一句话开篇**（50字以内）— 直接切入，不要背景铺垫。比如："买保险最烦条款看不懂，这篇文章不跟你拽术语。"
2. **核心保障：住院 + 外购药械**（最大篇幅）— 读者最可能触发理赔的场景
3. **大病保障：重疾0免赔 + 特药 + 先进疗法**（次大篇幅）— 产品的差异化优势
4. **加分项：康复 / 护工 / 异地转诊**（中等篇幅）— 让他觉得"考虑的还挺全"
5. **可选责任**（小篇幅）— 说清楚加不加
6. **免赔额怎么算**（一个例子讲清楚）— 不要列公式
7. **不保什么**（列举最常见几项）— 不要逐条翻译免责条款
8. **续保规则**— 讲清楚是否保证续保、停售后怎么办
9. **适合谁 / 不适合谁**— 按年龄、健康状况、预算给出判断
10. **结尾**（落在具体的下一步，不煽情）

图示按 `writing/视觉规范.md` 做成内嵌 SVG，不用 mermaid。不要为了塞图而塞图。


## h5-design

H5 页面风格统一为**浅色系 + 卡片式布局**，干净清爽，适合在手机和桌面端阅读条款分析。

### CSS 变量（复用此配置，保持视觉统一）

不同产品可更换 `--primary` 色系（医疗险用绿、重疾险用蓝、少儿险用紫），其余变量保持一致。

```css
:root {
  --primary: #1a6e5c;              /* 主色，按产品类型调整 */
  --primary-light: #e8f5f1;        /* 主色浅底 */
  --accent: #e8873a;               /* 强调色（可选责任等） */
  --accent-light: #fff5ed;         /* 强调色浅底 */
  --danger: #c0392b;               /* 警示色（免责等） */
  --danger-light: #fdecea;         /* 警示色浅底 */
  --bg: #f7f8fa;                   /* 页面背景 */
  --card: #ffffff;                 /* 卡片背景 */
  --text: #2c3e50;                 /* 正文颜色 */
  --text-secondary: #5a6c7d;       /* 辅助文字 */
  --border: #e2e8f0;               /* 边框 */
  --shadow: 0 1px 3px rgba(0,0,0,.06), 0 1px 2px rgba(0,0,0,.04);
  --radius: 12px;                  /* 卡片圆角 */
  --radius-sm: 8px;                /* 小元素圆角 */
}
```

### 产品配色对照

| 产品类型 | --primary | Hero 渐变 | 适用 |
|---------|-----------|-----------|------|
| 医疗险 | `#1a6e5c` | `#0d4f41 → #1a6e5c → #1e8b73` | 尊享e生等 |
| 成人重疾险 | `#1a4a6e` | `#0d2e4f → #1a4a6e → #1e6b9b` | 达尔文12号等 |
| 少儿重疾险 | `#7b4a9e` | `#4a1a6e → #7b4a9e → #9b6ec0` | 达尔文宝贝计划等 |

### 必含模块

| 模块 | 实现方式 | 说明 |
|------|---------|------|
| Hero 头图 | 渐变背景 + 产品名 + 公司名 + 日期 | 用 `::before` 伪元素加 SVG 纹理 |
| 导航目录 TOC | `flex` + 圆角胶囊链接，hover 变主色 | 锚点跳转到各 section |
| 产品概览 | `params-grid`（CSS Grid，最小列宽200px） | 6个参数卡片：年龄/期间/等待期/犹豫期/保额/续保 |
| 保障责任卡片 | `coverage-grid`（CSS Grid，最小列宽300px） | 每张卡片：标签（必选/可选）+ 编号 + 标题 + 描述 + 列表。顶部3px色条区分必选/可选 |
| 理赔流程 | `flow-row`（flex，步骤+箭头） | 横向5步，手机端竖向 |
| 关键参数表 | `table` 完整表格 | 保险期间/等待期/犹豫期/免赔额/给付比例/医院范围等 |
| 责任免除 | `exclusion-section` 折叠面板 | 红色 header + 编号，内容用 grid 排列 |
| 要点总结 | 绿色优势列表 + 红色风险列表 + 警示框 | 双列 grid，responsive |
| Footer | 条款来源 + 免责声明 | 居中，小字 |

### 不使用的旧风格元素

以下为旧版深色主题的设计元素，**新页面不再使用**：
- ❌ 深色背景（`#060812`）+ 玻璃拟态卡片 + 渐变光晕球动画
- ❌ Bento Grid 布局、手风琴列表、数字滚动计数、IntersectionObserver 滚动淡入
- ❌ 底部固定 CTA 栏
- ❌ 多色渐变文字（`--blue-a/b`, `--gold-a/b` 等）

### H5 页面代码模板

直接以 `static/pages/zhongan-zunxiang-esheng-2026/index.html` 为基准模板，复制后替换：
1. `<title>` 和 Hero 中的产品名、公司名
2. `:root` 中的 `--primary` 和 `.hero` 渐变背景
3. 概览参数、保障责任卡片、免责条款、赔付场景的具体内容
