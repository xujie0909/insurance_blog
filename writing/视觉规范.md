# 视觉规范

全站图示、数据图和 H5 页面都按这份规范来做。颜色在 `assets/css/extended/handbook.css` 里定义成 CSS 变量，明暗主题自动切换。

## 基调

手册讲的是钱和健康，读者本来就有防备，所以画面要**安静、可信**：大量留白，线条细，颜色少。图示是为了让读者更快看懂，不是装饰。

问自己一句：这张图读者看了，比读一段文字更快懂吗？不是，就不画。

## 颜色

只用语义角色，不在图里写死 hex 值。

| 角色 | CSS 变量 | 用在哪 |
|---|---|---|
| 底色 | `--fig-paper` / `--fig-paper-2` | 背景、次级容器 |
| 墨色 | `--fig-ink` | 主要文字、主要线框 |
| 次要 | `--fig-muted` / `--fig-soft` | 次要文字、默认箭头、注释 |
| 分隔线 | `--fig-rule` | 细分隔线 |
| 强调（松绿） | `--fig-accent` / `--fig-accent-tint` | 一张图里最关键的 1–2 个元素：“能赔”“该先做的” |
| 警示（砖红） | `--fig-caution` / `--fig-caution-tint` | 只用于“不赔”“风险”“误区” |
| 链接蓝 | `--fig-link` | 很少用，只在需要区分“外部”时 |

规则：

- 强调色一张图最多 1–2 处。什么都强调，等于没强调。
- 警示色只表达“不赔、风险”，不能拿来做装饰。
- 不用渐变、阴影、发光效果。
- 不用紫色、青色霓虹风。

## 字体

中国大陆访问 Google Fonts 不稳定，**不加载任何外部字体**。图里的文字继承系统字体栈：苹方、微软雅黑、Noto Sans CJK。

- 图内正文 14px，标题 16px 加粗，注释 12px
- 手机上图会缩小，所以图里的字**不能少于 12px**（按 680px 宽度计算）
- 不用等宽字体，除非是数字对齐表格

## 文章内嵌 SVG 图示

### 写法

```html
<figure class="fig">
<svg viewBox="0 0 680 320" role="img" aria-label="一句话描述这张图">
  <!-- 只用 handbook.css 里的语义类 -->
</svg>
<figcaption>图注：一句话说这张图要读者看出什么</figcaption>
</figure>
```

宽图在手机上会太小，横向内容多的图外面再包一层 `<div class="fig-scroll">`，让它可以横向滑动。

竖版窄图（viewBox 宽 360 左右，为手机设计的）用 `<figure class="fig fig-narrow">`，电脑上最宽 420px，不会被放大成一整屏。

提示框（`note-caution`）要短：只放最需要警示的一两段，操作步骤放到框外。

### 可用的类

| 类 | 效果 |
|---|---|
| `box` | 普通节点：底色填充 + 墨色描边 |
| `box-soft` | 次级节点、容器 |
| `box-focal` | 重点节点（强调色） |
| `box-caution` | 不赔、风险节点（警示色） |
| `box-dashed` | 可选、不确定 |
| `line` / `line-accent` / `line-caution` / `line-dashed` | 连线 |
| `head` / `head-accent` / `head-caution` | 箭头头部（放在 marker 里） |
| `t-title` / `t-sub` / `t-soft` / `t-accent` / `t-caution` | 文字层级 |
| `fill-accent` / `fill-caution` / `fill-muted` / `fill-soft` | 数据图的色块 |

箭头 marker 模板（每张图 id 加前缀，避免同页多张图冲突）：

```html
<defs>
  <marker id="a1-arrow" markerWidth="8" markerHeight="6" refX="7" refY="3" orient="auto">
    <polygon class="head" points="0 0, 8 3, 0 6"/>
  </marker>
</defs>
```

### 构图规则

画说明性图示时加载 `diagram-design` skill，遵守它的构图规则：

- 节点不超过 9 个，超过就拆成两张图
- 连线只走直角（转角圆角 r=8），不画斜线
- 连线标签和线之间留 6–10px 间隙，标签不压线
- 连线不重叠、不从无关节点背后穿过
- 圆角 4–8px，不用大圆角
- 图例放在底部，不放在图中间
- 结构尺寸按 4px 网格

但以下几点以本规范为准，覆盖 `diagram-design` 的默认值：

- 颜色用上面的 CSS 变量，不用它默认的橙色和 Geist 字体
- 输出是文章内嵌的 `<svg>`，不是独立 HTML 文件
- 标签用中文，不用全大写英文标签

### 数据图

画柱状图、折线图等数据图时加载 `dataviz` skill，按它的规范选图型和处理坐标轴，颜色仍用本规范的变量。

- 数据图下方写明数据来源和截止时间
- 一张图只讲一件事，标题直接写结论，比如“30 岁买重疾险，保费比 40 岁低 40% 左右”

### mermaid

只用来打草稿。定稿一律换成上面的内嵌 SVG。

## H5 互动页面

计算器、测算工具这类互动页面放在 `static/pages/tools/<name>/index.html`。

- 写之前加载 `frontend-design` skill，先写一版设计方案（配色、字体、布局），再对照本规范检查
- 配色沿用本规范的松绿和砖红，明暗两套
- 单文件，不依赖外部 CDN
- 手机优先：375px 宽度下不能横向滚动，按钮点击区域不小于 44px
- 不用入场动画，不用渐变光晕

产品解析的 H5 详解页沿用 `insurance-product-page` 已有的设计规范。

## 视觉审阅检查项

视觉审阅 agent 按这张表逐项检查截图：

1. 文字是否溢出、被截断、重叠
2. 明暗两种主题下文字对比度是否够，暗色下有没有“白底黑字”的突兀色块
3. 375px 手机宽度下图里的字是否还能看清（不小于约 11px）
4. 手机上有没有横向滚动条（`fig-scroll` 包裹的图除外）
5. 强调色是否超过 2 处，警示色是否被挪作他用
6. 同一篇文章里的图风格是否一致
7. 连线有没有斜线、压字、重叠
