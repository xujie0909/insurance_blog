# 写作规范

手册文章和产品解析共用这份规范。去 AI 味的句式规则单独放在 [AI味规则.md](AI味规则.md)，两份冲突时以 AI味规则.md 为准。

## 写给谁

主读者：25–40 岁、要给全家配保险的人。兼顾两类：替父母或孩子来查资料的人，刚工作、第一次想买保险的人。

他们的共同点：

- 保险知识近乎为零，“免赔额”“等待期”“现金价值”都不懂
- 医学知识近乎为零，条款里的病名对他们是乱码
- 多半在手机上读，碎片时间，注意力短
- 心里有防备：怕被坑、怕买错、怕“买了不赔”，不少人觉得保险就是骗人的

文章要做的事：用他听得懂的话讲清楚一件事，让他读完知道这跟自己有什么关系、下一步该做什么。

## 立场

1. **好处和局限都讲清楚。** 写明这个险种或这款产品适合谁、不适合谁、哪些情况不赔。读者没看到的缺点，买完后会变成“保险骗人”的证据。局限不用反复敲打，但必须写在读者看得到的地方，不藏在括号里。
2. **有判断就说判断。** “这项责任目前基本用不上”比“有一定局限性”有用。主观判断要写明是判断。
3. **不推销。** 不写“赶紧买”“名额有限”“再不买就停售”，不替读者做购买决定。可以写“如果你是 X 情况，优先考虑 Y”。
4. **不贬低同行和其他渠道。** 代理人、经纪人、互联网平台各有优缺点，照实写。
5. **免责声明由页面模板统一加在文末**，正文里不用再写。

## 手册文章的骨架

每篇手册文章按这个顺序组织，标题可以换成更自然的说法，但七块都要有：

1. **一句话说清**：放在正文最前面，用 `<div class="tldr">` 包起来。读者只读这一句也有收获。
2. **这事跟你有什么关系**：用一个具体的生活场景切入，第一段就让读者觉得“这说的是我”。
3. **正文**：按读者心里的问题顺序展开，不按教科书顺序。
4. **常见误区**：2–4 条，每条写清“很多人以为……，实际上……”。
5. **下一步读什么**：链接手册里 2–3 篇相关文章，说明为什么接着读它。
6. **参考资料**：列出实际引用的来源，带链接和访问日期。
7. **免责声明**：模板自动加，不用写。

篇幅：概念类 2000–3000 字，配置类可以到 4000 字。写不满就不写满。

产品解析沿用 `insurance-product-page` 的结构，但同样要有“适合谁 / 不适合谁”和“哪些情况不赔”。

## 语言

**场景优先于定义。** 不写“外购药械费用保险金是指……”，写“医生开了处方，说这药医院没有，你去外面买。这笔钱，这份保险帮你出。”

**术语第一次出现时用大白话解释**，之后可以直接用。常用对照：

| 条款原文 | 大白话 |
|---|---|
| 恶性肿瘤——重度 | 比较严重的癌症 |
| 恶性肿瘤——轻度 | 早期癌症、还没扩散的癌 |
| 脑卒中 | 脑中风 |
| 质子重离子治疗 | 精准打击肿瘤的高端放疗 |
| 外购药械 | 在院外药店买医生开的药和器械 |
| 特定药品 | 抗癌的靶向药、免疫药 |
| 免赔额 | 报销门槛，自己先出满这个数 |
| 等待期 | 买完到保险开始管用的那段时间 |
| 犹豫期 | 买了后悔可以全额退的期限 |
| 保险金 | 保险公司赔给你的钱 |
| 给付比例 | 按多少比例报销 |
| 现金价值 | 中途退保能拿回的钱 |

**比喻要贴切**，不用“保险是雨伞”这种人人都用过的比喻，除非它确实是解释这件事最好的方式。

**数字要具体。** “保费不贵”换成“30 岁每年几百块”；具体数字必须有来源。

**段落短，但别碎。** 手机上一段不超过 4–5 行。一个意思一段，不为了“节奏”把一句话拆成三段。

**开头不铺垫**，不写“随着生活水平提高”“在当今社会”。**结尾不升华**，落在一句具体的话或下一步行动上。

**结构用自然标题**，不用“一、二、三”论文框架。标题写成读者心里的问题，比如“有社保了还要买吗”。

## 信息来源

### 可以引用的

| 等级 | 来源 |
|---|---|
| 一级 | 国家金融监督管理总局（nfra.gov.cn）的规章、通知、答记者问；《保险法》原文；中国保险行业协会（iachina.cn）；国家医保局；保险公司官网公布的条款、费率表、年报、理赔年报 |
| 二级 | 新华社、人民网、央视、财新、第一财经、21 世纪经济报道、经济观察报等权威媒体的报道 |

### 不能引用的

自媒体、营销号、测评号、代理人个人号的结论；无出处的“据统计”；AI 生成的内容。二级来源里转述的数据，能追到一级原文就引一级。

### 时效

凡是会变的内容（预定利率、监管规定、产品在售状态、保费、统计数据），正文里注明“数据截至 X 年 X 月”。front matter 的 `lastmod` 填最后修改日期，`reviewed` 填最后核实日期。

### 找不到出处怎么办

不写。换一种不需要这个数字的说法，或者直接去掉这段。

## 必须问作者的素材

以下内容不能搜，也不能凭训练数据写，动笔前先列清单问作者：

- 具体产品的条款、费率表、健康告知、投保规则
- 具体产品的版本号、在售状态、销售渠道
- 作者本人的理赔案例、客户故事、观点和经历
- 作者想在文中表达的特定立场

可以自己搜、但必须标出处的：监管规定、法律条文、行业统计、公开的术语定义。
