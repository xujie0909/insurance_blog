# 写作工作区

这个目录不会发布到网站，放的是写作规则和审阅记录。

## 怎么用

在 Claude Code 里直接说要写什么，比如：

- “写一篇：等待期是什么”
- “帮我写 product/XXX 这款产品”
- “写合同术语这一批”
- “重审 darwin12 那篇”

会自动走 `insurance-article` 流水线，每篇文章做完后停下来，等你预览确认才会发布。

## 文件

| 文件 | 作用 | 谁维护 |
|---|---|---|
| `手册大纲.md` | 知识文章的主题、分类，以及还没写的文章 | 共同 |
| `读者问题汇总.md` | 读者提出、文章没解决的问题，等你决定要不要补 | **你** |
| `AI味规则.md` | 去 AI 味的第一层规则，优先级最高。看到有 AI 味的句子就加进去 | **你** |
| `读者人设.md` | 对抗审阅用的读者人设 | 你可以改 |
| `写作规范.md` | 读者、立场、文章骨架、语言、信息来源 | 共同 |
| `视觉规范.md` | 图示、数据图、H5 的颜色和构图规则 | 共同 |
| `reviews/<slug>.md` | 每篇文章的审阅记录：资料来源、核查结果、每轮读者意见和处理 | 自动生成 |
| `scripts/check_ai_words.py` | 按 AI味规则.md 的禁用词扫描文章 | — |
| `scripts/screenshot.py` | 视觉审阅截图（明暗 × 手机/电脑） | — |

## 本地预览

```
hugo server -D
```

然后打开 http://localhost:1313/posts/ 。手机预览用根目录的 `serve-lan.bat`。
